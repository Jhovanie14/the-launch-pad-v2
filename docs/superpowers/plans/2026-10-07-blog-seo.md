# Blog SEO Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace TLP's basic blog with the templated, SEO-led blog and editor from Aesthetic Training Hub: fixed post template, constrained rich text, a live SEO checklist that gates publishing, categories, JSON-LD, related posts, RSS and sitemap entries.

**Architecture:** Pure, tested modules in `lib/blog/` (template, rich text, slug, CTA, images, checklist, JSON-LD, save planning, row mapping) carry every rule. Public pages read through a cookie-free anon client (published only; RLS enforces it too). Admin reads and all writes go through `requireAdmin` + the service-role client, with writes in server actions (`app/actions/blog.ts`). UI is a port of ATH's components onto TLP's shadcn primitives and blue-900 accents.

**Tech Stack:** Next.js 16 App Router, React 19, Supabase (DB, RLS, Storage signed uploads), Tiptap v3, zod v4, shadcn/ui, sonner, Vitest.

**Spec:** `docs/superpowers/specs/2026-10-07-blog-seo-design.md`. Source being ported: `D:\Next\aesthetic-training-hub` (read-only reference — never modify it).

## Global Constraints

- Migrations are applied **manually via Supabase Dashboard → SQL Editor** (no local CLI). Commit the migration file with its task.
- RLS policies name roles explicitly (`to anon, authenticated`) and are preceded by `drop policy if exists` (idempotent).
- **No blog write goes through the anon or user client.** Every write is a server action: `requireAdmin(await createClient(), createAdminClient())`, then the service-role client.
- Public reads use a cookie-free anon client (pattern: `lib/products/queries.ts`) and always filter `published = true`.
- Vitest: `npm test`; config only includes `lib/**/*.test.ts` (tests sit next to source, e.g. `lib/blog/slug.test.ts`), `environment: "node"`. No `vi.mock()` of client modules.
- Site URL constant: `https://www.thelaunchpadwash.com` (from `lib/blog/site.ts`). Author default: `The Launch Pad`. Dates display in `America/Chicago`, `en-US`.
- Toasts: `import { toast } from "sonner"` (admin layout mounts `<Toaster />`).
- Primary actions in admin and public CTAs: `bg-blue-900 hover:bg-blue-800 text-white`. Headings on public blog pages: `text-blue-900`.
- Commit messages: conventional prefixes (`feat(blog):`, `feat(db):`, `chore(blog):`). **No Co-Authored-By trailer.** Work on branch `feat/blog-seo`, never on `main`.
- Windows dev machine; plain `git`/`npm` commands work in PowerShell and Git Bash.
- Do not touch seasonal branding or the admin sidebar's `filteredNavigation` hide-list. The sidebar already links `/admin/blog`.

## Review Focus

1. **A legacy live post is edited** (converted body, no meta description, no alt text) → saving refuses with "This post is live…" and lists the blockers; it never half-saves. Pinned in Task 6 (`save.test.ts`).
2. **Legacy content shapes** — Windows `\r\n`, a single paragraph, whitespace-only, null → converted without throwing; one paragraph yields no section. Pinned in Task 2 (`legacyContentToBody` tests) and mirrored by the SQL in Task 4.
3. **`?page=abc`, `?page=0`, `?page=999`** → page 1, page 1, 404. Pinned in Task 2 (`pageFromParam` tests) and Task 7 (page code).
4. **A forged cover URL** (another bucket, another host, `..`) → refused on save. Pinned in Task 2 (`images.test.ts`) and Task 6.
5. **Two drafts with the same title** → the second save gets "Another post already uses this web address", not a 500. Pinned in Task 6 (`saveErrorFromDb` test).

  });

  it("gives duplicate headings distinct anchors", () => {
    expect(sectionAnchors([{ heading: "Costs" }, { heading: "Costs" }, { heading: "" }])).toEqual([
      "costs",
      "costs-2",
      "section-3",
    ]);
  });

describe("legacyContentToBody", () => {
  const para = (text: string) => ({ type: "paragraph", content: [{ type: "text", text }] });

  it("makes the first paragraph the intro and the rest one untitled section", () => {
    expect(legacyContentToBody("First line\nwraps\n\nSecond\n\n\nThird")).toEqual({
      intro: "First line wraps",
      sections: [{ heading: "", content: { type: "doc", content: [para("Second"), para("Third")] } }],
    });
  });

  it("handles Windows line endings", () => {
    expect(legacyContentToBody("One\r\n\r\nTwo").intro).toBe("One");
    expect(legacyContentToBody("One\r\n\r\nTwo").sections).toHaveLength(1);
  });

  it("produces no section from a single paragraph", () => {
    expect(legacyContentToBody("Only this")).toEqual({ intro: "Only this", sections: [] });
  });

  it("returns the empty template for nothing", () => {
    expect(legacyContentToBody(null)).toEqual({ intro: "", sections: [] });
    expect(legacyContentToBody("  \n\n  ")).toEqual({ intro: "", sections: [] });
  });
});

/**
 * The shape of a blog post's templated content, and the pure helpers that
 * read it. Shared by the editor, the server actions, the public page and the
 * SEO checklist so they cannot disagree about what a post contains.
 *
 * The template is fixed on purpose: an intro, then H2-headed sections, then
 * FAQs, then a call to action. There is no free-form page builder — the
 * structure IS the SEO advice. (Ported from Aesthetic Training Hub.)
 */
import { countWords, normaliseRichDoc, richDocText, type RichDoc } from "./rich-text";
import { slugify } from "./slug";

export const DEFAULT_AUTHOR = "The Launch Pad";

export const BLOG_LIMITS = {
  title: 140,
  seoTitle: 120,
  metaDescription: 320,
  focusKeyword: 80,
  excerpt: 400,
  coverAlt: 250,
  intro: 3_000,
  sectionHeading: 140,
  sections: 30,
  faqs: 20,
  faqQuestion: 250,
  faqAnswer: 2_000,
  ctaButton: 60,
  author: 80,
} as const;

export type BlogSection = { heading: string; content: RichDoc };
export type BlogBody = { intro: string; sections: BlogSection[] };
export type BlogFaq = { question: string; answer: string };

export const EMPTY_BODY: BlogBody = { intro: "", sections: [] };

function isObject(v: unknown): v is Record<string, unknown> {
  return typeof v === "object" && v !== null && !Array.isArray(v);
}

function str(v: unknown, max: number): string {
  return typeof v === "string" ? v.trim().slice(0, max) : "";
}

/** Multi-paragraph text keeps its paragraph breaks; everything else is trimmed. */
function multiline(v: unknown, max: number): string {
  if (typeof v !== "string") return "";
  return v.replace(/\r\n?/g, "\n").replace(/\n{3,}/g, "\n\n").trim().slice(0, max);
}

/** Never throws: anything malformed comes back as the empty template. */
export function normaliseBody(input: unknown): BlogBody {
  if (!isObject(input)) return { intro: "", sections: [] };
  const sections = Array.isArray(input.sections) ? input.sections : [];
  return {
    intro: multiline(input.intro, BLOG_LIMITS.intro),
    sections: sections
      .filter(isObject)
      .slice(0, BLOG_LIMITS.sections)
      .map((s) => ({
        heading: str(s.heading, BLOG_LIMITS.sectionHeading),
        content: normaliseRichDoc(s.content),
      })),
  };
}

export function normaliseFaq(input: unknown): BlogFaq[] {
  if (!Array.isArray(input)) return [];
  return (
    input
      .filter(isObject)
      .map((f) => ({
        question: str(f.question, BLOG_LIMITS.faqQuestion),
        answer: multiline(f.answer, BLOG_LIMITS.faqAnswer),
      }))
      // A half-filled pair is a row someone added and abandoned — drop it
      // rather than publish a question with no answer into FAQPage markup.
      .filter((f) => f.question && f.answer)
      .slice(0, BLOG_LIMITS.faqs)
  );
}

/** Text split into the paragraphs it is rendered as. */
export function introParagraphs(intro: string): string[] {
  return intro
    .split(/\n\s*\n/)
    .map((p) => p.replace(/\s*\n\s*/g, " ").trim())
    .filter(Boolean);
}

/**
 * Stable, unique fragment ids for the section headings — the table of
 * contents links to them, so they must not collide when two headings slugify
 * the same.
 */
export function sectionAnchors(sections: Pick<BlogSection, "heading">[]): string[] {
  const used = new Map<string, number>();
  return sections.map((s, i) => {
    const base = slugify(s.heading) || `section-${i + 1}`;
    const n = used.get(base) ?? 0;
    used.set(base, n + 1);
    return n === 0 ? base : `${base}-${n + 1}`;
  });
}

/** Words a reader actually reads: intro, headings, section bodies, FAQs. */
export function postWordCount(post: { body: BlogBody; faq: BlogFaq[] }): number {
  const parts = [
    post.body.intro,
    ...post.body.sections.flatMap((s) => [s.heading, richDocText(s.content)]),
    ...post.faq.flatMap((f) => [f.question, f.answer]),
  ];
  return countWords(parts.join("\n"));
}

/** At ~220 words a minute, never less than one. */
export function readingMinutes(words: number): number {
  return Math.max(1, Math.round(words / 220));
}

/** The listing/meta summary: excerpt, else meta description, else the start of the intro. */
export function postSummary(post: {
  excerpt: string | null;
  metaDescription: string | null;
  body: BlogBody;
}): string {
  if (post.excerpt?.trim()) return post.excerpt.trim();
  if (post.metaDescription?.trim()) return post.metaDescription.trim();
  const first = introParagraphs(post.body.intro)[0] ?? "";
  return first.length > 200 ? `${first.slice(0, 197).trimEnd()}…` : first;
}

/**
 * The plain-text `content` of a pre-template post, as the template. Mirrors
 * the backfill in supabase/migrations/20261007000000_blog_seo.sql — change
 * one, change both.
 */
export function legacyContentToBody(content: string | null | undefined): BlogBody {
  const paragraphs = introParagraphs((content ?? "").replace(/\r\n?/g, "\n"));
  if (paragraphs.length === 0) return { intro: "", sections: [] };
  const [first, ...rest] = paragraphs;
  return {
    intro: first.slice(0, BLOG_LIMITS.intro),
    sections: rest.length
      ? [
          {
            heading: "",
            content: {
              type: "doc",
              content: rest.map((text) => ({ type: "paragraph", content: [{ type: "text", text }] })),
            },
          },
        ]
      : [],
  };
}

const TIME_ZONE = "America/Chicago";

/** "October 1, 2026", in Houston time. */
export function formatPostDate(d: Date): string {
  return d.toLocaleDateString("en-US", { month: "long", day: "numeric", year: "numeric", timeZone: TIME_ZONE });
}

export function postDayKey(d: Date): string {
  return d.toLocaleDateString("en-CA", { timeZone: TIME_ZONE });
}

/** `?page=` as a page number: whole numbers above 1, everything else is page 1. */
export function pageFromParam(raw: string | string[] | undefined): number {
  const n = Number(Array.isArray(raw) ? raw[0] : raw);
  return Number.isInteger(n) && n > 1 ? n : 1;
}

/**
 * Blog cover images live in the PUBLIC `blog-images` Storage bucket: covers
 * must be fetchable by crawlers and link-preview bots (og:image) with no
 * session, at a stable URL.
 *
 * New uploads get a fresh uuid path (`posts/<uuid>.<ext>`), so a URL's content
 * never changes and can be cached for a year. Posts written before the
 * template stored `cover-images/<timestamp>.<ext>`; those URLs stay valid.
 *
 * The bucket's own size cap and MIME allow-list (set by the 20261007 migration)
 * are the real enforcement; validateBlogImage gives the same answer earlier.
 */

export const BLOG_BUCKET = "blog-images";
export const BLOG_IMAGE_MAX_BYTES = 5 * 1024 * 1024;
export const BLOG_IMAGE_MIME_TYPES = ["image/jpeg", "image/png", "image/webp"] as const;

const EXTENSION: Record<(typeof BLOG_IMAGE_MIME_TYPES)[number], string> = {
  "image/jpeg": "jpg",
  "image/png": "png",
  "image/webp": "webp",
};

export function validateBlogImage(
  mime: string,
  sizeBytes: number,
): { ok: true; extension: string } | { ok: false; error: string } {
  if (!(BLOG_IMAGE_MIME_TYPES as readonly string[]).includes(mime)) {
    return { ok: false, error: "Use a JPG, PNG or WebP image." };
  }
  if (!Number.isFinite(sizeBytes) || sizeBytes <= 0) {
    return { ok: false, error: "That file is empty." };
  }
  if (sizeBytes > BLOG_IMAGE_MAX_BYTES) {
    return { ok: false, error: "Images must be 5 MB or smaller." };
  }
  return { ok: true, extension: EXTENSION[mime as keyof typeof EXTENSION] };
}

const UPLOAD_PATH =

  return process.env.NEXT_PUBLIC_SUPABASE_URL ?? "";
}

export function blogImageUrl(path: string, supabaseUrl: string = envUrl()): string {

}

/** Folder segments and a file name of safe characters, ending in an image extension. */
const SAFE_OBJECT = /^[A-Za-z0-9_-]+(?:\/[A-Za-z0-9_-]+)*\.(?:jpe?g|png|webp)$/i;

/**
 * True only for an object in OUR blog bucket — so a forged save cannot point a
 * post's cover (and its og:image) at an arbitrary host or another bucket.
 */
export function isBlogImageUrl(url: unknown, supabaseUrl: string = envUrl()): url is string {
  if (typeof url !== "string" || !/^https?:\/\//.test(supabaseUrl)) return false;
  const base = bucketBase(supabaseUrl);
  return url.startsWith(base) && SAFE_OBJECT.test(url.slice(base.length));
}

export function blogImagePathFromUrl(url: string, supabaseUrl: string = envUrl()): string | null {
  return isBlogImageUrl(url, supabaseUrl) ? url.slice(bucketBase(supabaseUrl).length) : null;
}

export function imageMimeFromUrl(url: string): string {
  if (/\.png$/i.test(url)) return "image/png";
  if (/\.webp$/i.test(url)) return "image/webp";
  return "image/jpeg";
}

  select p.id, x.ord,
         btrim(regexp_replace(x.chunk, '\s*\n\s*', ' ', 'g'), E' \t\n') as para
  from public.blog_posts p
  cross join lateral regexp_split_to_table(
    regexp_replace(coalesce(p.content, ''), E'\r\n?', E'\n', 'g'),
    E'\n\\s*\n'

  where p.body = '{"intro":"","sections":[]}'::jsonb
    and btrim(coalesce(p.content, '')) <> ''

  select id, para, row_number() over (partition by id order by ord) as n
  from chunks
  where para <> ''

         left(max(para) filter (where n = 1), 3000) as intro,

/**
 * Public blog reads. Every query filters `published = true` — RLS enforces
 * the same, but a draft must never depend on one layer alone.
 *
 * Deliberately NOT utils/supabase/server.ts: that client reads cookies, which
 * opts a route into dynamic rendering. These reads are the same for every
 * visitor, so an anon client keeps the post pages cacheable (same reasoning
 * as lib/products/queries.ts).
 */

export const BLOG_PAGE_SIZE = 12;

function blogClient() {
  return createClient(process.env.NEXT_PUBLIC_SUPABASE_URL!, process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY!, {
    auth: { persistSession: false, autoRefreshToken: false },
  });
}

/** PostgREST answers a range past the end with PGRST103 — that is "no posts", not a failure. */
const RANGE_NOT_SATISFIABLE = "PGRST103";

/** One page of published posts, newest first. Returns an empty page rather than throwing. */
export async function publishedPostsPage(opts: {
  page: number;
  categoryId?: string;
}): Promise<{ posts: BlogCard[]; total: number; pageCount: number }> {
  const page = Math.max(1, Math.floor(opts.page));
  const from = (page - 1) * BLOG_PAGE_SIZE;
  let query = blogClient().from("blog_posts").select(CARD_COLUMNS, { count: "exact" }).eq("published", true);
  if (opts.categoryId) query = query.eq("category_id", opts.categoryId);
  const { data, error, count } = await query
    .order("published_at", { ascending: false })
    .order("id", { ascending: false })
    .range(from, from + BLOG_PAGE_SIZE - 1);

  if (error) {
    if (error.code !== RANGE_NOT_SATISFIABLE) logger.error("blog.list_failed", error);
    return { posts: [], total: 0, pageCount: 1 };
  }
  const total = count ?? 0;
  return {
    posts: (data as unknown as CardRow[]).map(toCard),
    total,
    pageCount: Math.max(1, Math.ceil(total / BLOG_PAGE_SIZE)),
  };
}

/**
 * Up to `limit` other published posts — same category first, topped up with
 * the newest posts from anywhere so a category of one still gets a row.
 */
export async function relatedPosts(
  post: { id: string; categoryId: string | null },
  limit = 3,
): Promise<BlogCard[]> {
  const db = blogClient();
  let sameCategory: BlogCard[] = [];
  if (post.categoryId) {
    const { data } = await db
      .from("blog_posts")
      .select(CARD_COLUMNS)
      .eq("published", true)
      .eq("category_id", post.categoryId)
      .neq("id", post.id)
      .order("published_at", { ascending: false })
      .limit(limit);
    sameCategory = ((data ?? []) as unknown as CardRow[]).map(toCard);
  }
  if (sameCategory.length >= limit) return sameCategory;

  const { data } = await db
    .from("blog_posts")
    .select(CARD_COLUMNS)
    .eq("published", true)
    .neq("id", post.id)
    .order("published_at", { ascending: false })
    .limit(limit + sameCategory.length);
  const seen = new Set(sameCategory.map((p) => p.id));
  const recent = ((data ?? []) as unknown as CardRow[]).map(toCard).filter((p) => !seen.has(p.id));
  return [...sameCategory, ...recent].slice(0, limit);
}

/**
 * /blog, each category with a published post, and every published post.
 * Fail-soft: a blog problem must not take the rest of the sitemap down, so
 * /blog is always listed and failures only drop the blog's own entries.
 */
export async function blogSitemapEntries(base: string): Promise<MetadataRoute.Sitemap> {
  const posts = await publishedSlugs();
  const categories = posts.length ? await publicCategories() : [];
  const newest = posts.reduce<Date | null>((max, p) => (!max || p.updatedAt > max ? p.updatedAt : max), null);
  return [
    { url: `${base}/blog`, lastModified: newest ?? new Date(), changeFrequency: "weekly", priority: 0.7 },
    ...categories.map((c) => ({
      url: `${base}/blog/category/${c.slug}`,
      lastModified: c.lastModified,
      changeFrequency: "weekly" as const,
      priority: 0.5,
    })),
    ...posts.map((p) => ({
      url: `${base}/blog/${p.slug}`,
      lastModified: p.updatedAt,
      changeFrequency: "monthly" as const,
      priority: 0.6,
    })),
  ];
}

import { z } from "zod";
import { normaliseCta, type BlogCta } from "./cta";
import { isBlogImageUrl } from "./images";
import { BLOG_LIMITS, DEFAULT_AUTHOR, normaliseBody, normaliseFaq, type BlogBody, type BlogFaq } from "./post";
import { seoChecklist } from "./seo-checklist";
import { resolveSlugForSave } from "./slug";

/**
 * Every rule a save has to satisfy, as pure functions — the server action is
 * left with only the reads and the write.
 *
 * The editor posts a plain object (a post is a nested document). It is
 * untrusted all the same: scalars are validated here, and body/faq/cta are
 * rebuilt from an allow-list by the lib/blog normalisers.
 */

export type SaveIntent = "save" | "publish";

export type ExistingPost = { id: string; slug: string; published: boolean; published_at: string | null };

export type BlogPostWrite = {
  slug: string;
  title: string;
  seo_title: string | null;
  meta_description: string | null;
  focus_keyword: string | null;
  excerpt: string | null;
  cover_image: string | null;
  cover_image_alt: string | null;
  category_id: string | null;
  author: string;
  body: BlogBody;
  faq: BlogFaq[];
  cta: BlogCta | null;
  published: boolean;
  published_at: string | null;
  updated_at: string;
};

export type SaveFailure = {
  ok: false;
  error: string;
  fieldErrors?: Record<string, string>;
  /** Labels of the required checklist items still missing. */
  blockers?: string[];
};

const text = (max: number) =>
  z
    .string()
    .max(max, `Keep this to ${max.toLocaleString("en-US")} characters or fewer`)
    .optional()
    .transform((v) => v?.trim() ?? "");

const postInputSchema = z.object({
  id: z.uuid().optional(),
  title: z
    .string()
    .trim()
    .min(1, "Give the post a title before saving")
    .max(BLOG_LIMITS.title, `Keep the title to ${BLOG_LIMITS.title} characters or fewer`),
  seoTitle: text(BLOG_LIMITS.seoTitle),
  metaDescription: text(BLOG_LIMITS.metaDescription),
  focusKeyword: text(BLOG_LIMITS.focusKeyword),
  excerpt: text(BLOG_LIMITS.excerpt),
  slug: z.string().max(200).optional(),
  coverImage: z.string().max(1000).nullable().optional(),
  coverImageAlt: text(BLOG_LIMITS.coverAlt),
  categoryId: z.uuid().nullable().optional(),
  author: text(BLOG_LIMITS.author),
  body: z.unknown(),
  faq: z.unknown(),
  cta: z.unknown(),
});

export type PostInput = z.infer<typeof postInputSchema>;

function fieldErrorsFrom(error: z.ZodError): Record<string, string> {
  const out: Record<string, string> = {};
  for (const issue of error.issues) {
    const key = String(issue.path[0] ?? "form");
    if (!out[key]) out[key] = issue.message;
  }
  return out;
}

export function parsePostInput(input: unknown): { ok: true; data: PostInput } | SaveFailure {
  const parsed = postInputSchema.safeParse(input);
  if (!parsed.success) {
    return { ok: false, error: "Some fields need attention.", fieldErrors: fieldErrorsFrom(parsed.error) };
  }
  return { ok: true, data: parsed.data };
}

/**
 * What to write, or why not.
 *
 * Required checklist items block PUBLISH, never a draft save — EXCEPT when the
 * post is already live: saving a published post changes the live page, so it
 * is held to the publishing bar. To save a live post half-finished, unpublish
 * it first.
 */
export function planSave(args: {
  data: PostInput;
  intent: SaveIntent;
  existing: ExistingPost | null;
  categoryExists: boolean;
  now: Date;
  internalHosts: string[];
  supabaseUrl?: string;
}): { ok: true; values: BlogPostWrite } | SaveFailure {
  const { data: d, intent, existing, now } = args;

  const coverImage = d.coverImage ? d.coverImage : null;
  if (coverImage !== null && !isBlogImageUrl(coverImage, args.supabaseUrl)) {
    return {
      ok: false,
      error: "That cover image was not uploaded here. Upload it again.",
      fieldErrors: { coverImage: "Upload the cover image again." },
    };
  }

  const slugDecision = resolveSlugForSave({
    requested: d.slug,
    title: d.title,
    existing: existing ? { slug: existing.slug, publishedAt: existing.published_at } : null,
  });
  if (!slugDecision.ok) {
    return { ok: false, error: slugDecision.error, fieldErrors: { slug: slugDecision.error } };
  }

  if (d.categoryId && !args.categoryExists) {
    return {
      ok: false,
      error: "That category no longer exists. Choose another.",
      fieldErrors: { categoryId: "Choose another category." },
    };
  }

  const body = normaliseBody(d.body);
  const faq = normaliseFaq(d.faq);
  const cta = normaliseCta(d.cta);

  const goingLive = intent === "publish" || !!existing?.published;
  if (goingLive) {
    const checklist = seoChecklist({
      title: d.title,
      seoTitle: d.seoTitle,
      metaDescription: d.metaDescription,
      slug: slugDecision.slug,
      focusKeyword: d.focusKeyword,
      coverImage,
      coverImageAlt: d.coverImageAlt,
      body,
      faq,
      cta,
      internalHosts: args.internalHosts,
    });
    if (!checklist.canPublish) {
      return {
        ok: false,
        error:
          existing?.published && intent === "save"
            ? "This post is live, so it needs everything a published post needs. Fill in the items below, or unpublish it first."
            : "A few things are needed before this can be published.",
        blockers: checklist.blockers.map((b) => b.label),
      };
    }
  }

  const published = intent === "publish" ? true : (existing?.published ?? false);
  return {
    ok: true,
    values: {
      slug: slugDecision.slug,
      title: d.title,
      seo_title: d.seoTitle || null,
      meta_description: d.metaDescription || null,
      focus_keyword: d.focusKeyword || null,
      excerpt: d.excerpt || null,
      cover_image: coverImage,
      cover_image_alt: d.coverImageAlt || null,
      category_id: d.categoryId ?? null,
      author: d.author || DEFAULT_AUTHOR,
      body,
      faq,
      cta,
      published,
      // First publication only: an unpublish/republish keeps the original
      // date, and with it the locked slug.
      published_at: existing?.published_at ?? (published ? now.toISOString() : null),
      updated_at: now.toISOString(),
    },
  };
}

/** A failed insert/update the editor can explain, or null for a genuine fault. */
export function saveErrorFromDb(error: { code?: string } | null): SaveFailure | null {
  if (error?.code === "23505") {
    const message = "Another post already uses this web address. Change it slightly.";
    return { ok: false, error: message, fieldErrors: { slug: message } };
  }
  return null;
}

import { revalidatePath } from "next/cache";
import { z } from "zod";
import { AuthError, requireAdmin } from "@/lib/auth/guards";
import {
  BLOG_BUCKET,
  blogImagePathFromUrl,

import {
  parsePostInput,
  planSave,
  saveErrorFromDb,
  type ExistingPost,
  type SaveFailure,
  type SaveIntent,

/**
 * Blog admin actions. Each re-checks the admin role (requireAdmin) and then
 * writes with the service role: blog_posts has no write policies at all
 * (20261007000000_blog_seo.sql), so this file is the only way in.
 */

export type BlogSaveResult = { ok: true; id: string; slug: string; published: boolean } | SaveFailure;
export type BlogActionResult = { ok: true } | { ok: false; error: string };

const NOT_AUTHORISED = { ok: false as const, error: "Not authorised" };

/** The service-role client if the caller is an admin, else null. */
async function adminOrNull() {
  const admin = createAdminClient();
  try {
    await requireAdmin(await createClient(), admin);
    return admin;
  } catch (e) {
    if (e instanceof AuthError) return null;
    throw e;
  }
}

function revalidateBlog() {
  // "layout" covers every page under /blog: posts, categories, preview, RSS.
  revalidatePath("/blog", "layout");
  revalidatePath("/admin/blog", "layout");
  revalidatePath("/sitemap.xml");
}

/**
 * Save a post — as a draft, or (intent "publish") save and publish in one
 * write, so what goes live is exactly what the editor was looking at.
 */
export async function saveBlogPost(input: unknown, intent: SaveIntent = "save"): Promise<BlogSaveResult> {
  const admin = await adminOrNull();
  if (!admin) return NOT_AUTHORISED;

  const parsed = parsePostInput(input);
  if (!parsed.ok) return parsed;
  const d = parsed.data;

  let existing: ExistingPost | null = null;
  if (d.id) {
    const { data } = await admin
      .from("blog_posts")
      .select("id, slug, published, published_at")
      .eq("id", d.id)
      .maybeSingle();
    if (!data) return { ok: false, error: "That post no longer exists." };
    existing = data;
  }

  let categoryExists = true;
  if (d.categoryId) {
    const { data } = await admin.from("blog_categories").select("id").eq("id", d.categoryId).maybeSingle();
    categoryExists = !!data;
  }

  const plan = planSave({ data: d, intent, existing, categoryExists, now: new Date(), internalHosts: [SITE_HOST] });
  if (!plan.ok) return plan;

  const { data: saved, error } = existing
    ? await admin.from("blog_posts").update(plan.values).eq("id", existing.id).select("id, slug, published").single()
    : await admin.from("blog_posts").insert(plan.values).select("id, slug, published").single();
  if (error) {
    const known = saveErrorFromDb(error);
    if (known) return known;
    throw new Error(`Failed to save blog post: ${error.message}`);
  }

  revalidateBlog();
  return { ok: true, id: saved.id, slug: saved.slug, published: saved.published };
}

/** Take a post off the site. Its slug stays locked (published_at survives). */
export async function unpublishBlogPost(id: string): Promise<BlogActionResult> {
  const admin = await adminOrNull();
  if (!admin) return NOT_AUTHORISED;
  if (!z.uuid().safeParse(id).success) return { ok: false, error: "Post not found" };

  const { data, error } = await admin
    .from("blog_posts")
    .update({ published: false, updated_at: new Date().toISOString() })
    .eq("id", id)
    .eq("published", true)
    .select("id")
    .maybeSingle();
  if (error) throw new Error(`Failed to unpublish: ${error.message}`);
  if (!data) return { ok: false, error: "That post is not published." };
  revalidateBlog();
  return { ok: true };
}

/**
 * Delete a draft that has NEVER been published. A post that has been live
 * keeps its row (unpublish it instead): its URL has been crawled and linked,
 * and keeping the row keeps that slug from being reused.
 */
export async function deleteBlogPost(id: string): Promise<BlogActionResult> {
  const admin = await adminOrNull();
  if (!admin) return NOT_AUTHORISED;
  if (!z.uuid().safeParse(id).success) return { ok: false, error: "Post not found" };

  const { data: deleted, error } = await admin
    .from("blog_posts")
    .delete()
    .eq("id", id)
    .is("published_at", null)
    .select("cover_image")
    .maybeSingle();
  if (error) throw new Error(`Failed to delete: ${error.message}`);
  if (!deleted) return { ok: false, error: "Only drafts that have never been published can be deleted." };

  // Best effort, after the row is gone — the row is the source of truth.
  const path = deleted.cover_image ? blogImagePathFromUrl(deleted.cover_image) : null;
  if (path) {
    const { count } = await admin
      .from("blog_posts")
      .select("id", { count: "exact", head: true })
      .eq("cover_image", deleted.cover_image);
    if (!count) await admin.storage.from(BLOG_BUCKET).remove([path]);
  }
  revalidateBlog();
  return { ok: true };
}

export type BlogImageTicket = { ok: true; path: string; token: string; url: string } | { ok: false; error: string };

/**
 * Step 1 of a cover upload: validate the claimed type/size and mint a signed
 * upload URL for a fresh path. The browser uploads straight to Storage, so a
 * photo never passes through a Vercel function's 4.5 MB body limit.
 */
export async function requestBlogImageUpload(mime: string, sizeBytes: number): Promise<BlogImageTicket> {
  const admin = await adminOrNull();
  if (!admin) return NOT_AUTHORISED;
  const check = validateBlogImage(String(mime), Number(sizeBytes));
  if (!check.ok) return check;

  const path = newBlogImagePath(check.extension);
  const { data, error } = await admin.storage.from(BLOG_BUCKET).createSignedUploadUrl(path);
  if (error || !data) {
    return {
      ok: false,
      error: /not found/i.test(error?.message ?? "")
        ? "Image storage is not set up yet — run the blog migration."
        : "Couldn't start the upload. Try again.",
    };
  }
  return { ok: true, path, token: data.token, url: blogImageUrl(path) };
}

/** Step 2: re-check what ACTUALLY landed (a signed URL pins neither type nor size). */
export async function confirmBlogImageUpload(path: string): Promise<BlogActionResult> {
  const admin = await adminOrNull();
  if (!admin) return NOT_AUTHORISED;
  if (!isBlogUploadPath(path)) return { ok: false, error: "Upload not recognised." };

  const storage = admin.storage.from(BLOG_BUCKET);
  const { data, error } = await storage.info(path);
  if (error || !data) return { ok: false, error: "Upload not found — please try again." };

  const check = validateBlogImage(data.contentType ?? "", data.size ?? 0);
  if (!check.ok) {
    await storage.remove([path]);
    return check;
  }
  return { ok: true };
}

export type BlogCategoryFormState = { ok: boolean; fieldErrors?: Record<string, string>; formError?: string };

const categorySchema = z.object({

function categoryFieldErrors(error: z.ZodError): Record<string, string> {
  const out: Record<string, string> = {};
  for (const issue of error.issues) {
    const key = String(issue.path[0] ?? "form");
    if (!out[key]) out[key] = issue.message;
  }
  return out;

export async function createBlogCategory(
  _prev: BlogCategoryFormState,
  formData: FormData,
): Promise<BlogCategoryFormState> {
  const admin = await adminOrNull();
  if (!admin) return { ok: false, formError: "Not authorised" };
  const parsed = parseCategoryForm(formData);
  if (!parsed.success) return { ok: false, fieldErrors: categoryFieldErrors(parsed.error) };

  const requested = String(formData.get("slug") || "").trim();
  const slug = slugify(requested || parsed.data.name);
  if (!isValidSlug(slug)) return { ok: false, fieldErrors: { slug: "Use letters, numbers and hyphens." } };

  const { error } = await admin.from("blog_categories").insert({
    slug,
    name: parsed.data.name,
    description: parsed.data.description || null,
    sort_order: parsed.data.sortOrder ?? 0,
  });
  if (error?.code === "23505") {
    return { ok: false, fieldErrors: { slug: "A category with this web address already exists." } };
  }
  if (error) throw new Error(`Failed to create category: ${error.message}`);
  revalidateBlog();
  return { ok: true };
}

/** Name, description and order only — the slug is a public URL and stays put. */
export async function updateBlogCategory(
  _prev: BlogCategoryFormState,
  formData: FormData,
): Promise<BlogCategoryFormState> {
  const admin = await adminOrNull();
  if (!admin) return { ok: false, formError: "Not authorised" };
  const id = z.uuid().safeParse(formData.get("id"));
  if (!id.success) return { ok: false, formError: "Category not found" };
  const parsed = parseCategoryForm(formData);
  if (!parsed.success) return { ok: false, fieldErrors: categoryFieldErrors(parsed.error) };

  const { data, error } = await admin
    .from("blog_categories")
    .update({
      name: parsed.data.name,
      description: parsed.data.description || null,
      sort_order: parsed.data.sortOrder ?? 0,
      updated_at: new Date().toISOString(),
    })
    .eq("id", id.data)
    .select("id")
    .maybeSingle();
  if (error) throw new Error(`Failed to update category: ${error.message}`);
  if (!data) return { ok: false, formError: "Category not found" };
  revalidateBlog();
  return { ok: true };
}

/** Only an unused category can go — posts are never silently uncategorised. */
export async function deleteBlogCategory(id: string): Promise<BlogActionResult> {
  const admin = await adminOrNull();
  if (!admin) return NOT_AUTHORISED;
  if (!z.uuid().safeParse(id).success) return { ok: false, error: "Category not found" };

  const { count } = await admin
    .from("blog_posts")
    .select("id", { count: "exact", head: true })
    .eq("category_id", id);
  if (count) return { ok: false, error: "Posts still use this category. Move them to another one first." };

  const { data, error } = await admin.from("blog_categories").delete().eq("id", id).select("id").maybeSingle();
  if (error) throw new Error(`Failed to delete category: ${error.message}`);
  if (!data) return { ok: false, error: "Category not found" };
  revalidateBlog();
  return { ok: true };
}

  const { slug } = await params;
  // publishedPostBySlug is React-cached, so the page's own call is free.
  const post = await publishedPostBySlug(slug);

import { imageMimeFromUrl } from "@/lib/blog/images";
import { rssPosts } from "@/lib/blog/queries";
import { SITE_URL } from "@/lib/blog/site";

/**
 * RSS 2.0 feed of the newest published posts, advertised from /blog's <head>.
 * Published-only by construction: rssPosts filters on `published`.
 */
export const revalidate = 300;

function xml(s: string): string {
  return s
    .replace(/&/g, "&amp;")
    .replace(/</g, "&lt;")
    .replace(/>/g, "&gt;")
    .replace(/"/g, "&quot;")
    .replace(/'/g, "&apos;");
}

export async function GET() {
  const posts = await rssPosts(30);
  const newest = posts[0]?.updatedAt ?? new Date();

  const items = posts
    .map((p) => {
      const url = `${SITE_URL}/blog/${p.slug}`;
      const summary = (p.excerpt ?? p.metaDescription ?? "").trim();
      return [
        "    <item>",
        `      <title>${xml(p.title)}</title>`,
        `      <link>${xml(url)}</link>`,
        `      <guid isPermaLink="true">${xml(url)}</guid>`,
        p.publishedAt ? `      <pubDate>${p.publishedAt.toUTCString()}</pubDate>` : null,
        p.categoryName ? `      <category>${xml(p.categoryName)}</category>` : null,
        summary ? `      <description>${xml(summary)}</description>` : null,
        p.coverImage
          ? `      <enclosure url="${xml(p.coverImage)}" type="${imageMimeFromUrl(p.coverImage)}" length="0" />`
          : null,
        "    </item>",
      ]
        .filter(Boolean)
        .join("\n");
    })
    .join("\n");

  const body = `<?xml version="1.0" encoding="UTF-8"?>
<rss version="2.0" xmlns:atom="http://www.w3.org/2005/Atom">
  <channel>
    <title>The Launch Pad — Car Care Tips &amp; News</title>
    <link>${xml(`${SITE_URL}/blog`)}</link>
    <description>Practical car care advice from The Launch Pad in Houston.</description>
    <language>en-us</language>
    <lastBuildDate>${newest.toUTCString()}</lastBuildDate>
    <atom:link href="${xml(`${SITE_URL}/blog/rss.xml`)}" rel="self" type="application/rss+xml" />
${items}
  </channel>
</rss>
`;

  return new Response(body, {
    headers: {
      "Content-Type": "application/rss+xml; charset=utf-8",
      "Cache-Control": "public, max-age=0, s-maxage=300, stale-while-revalidate=600",
    },
  });
}

"use client";

import { useRef, useState } from "react";
import { ImagePlus, Loader2, RefreshCw } from "lucide-react";
import { confirmBlogImageUpload, requestBlogImageUpload } from "@/app/actions/blog";
import { Input } from "@/components/ui/input";
import { BLOG_BUCKET, BLOG_IMAGE_MIME_TYPES, validateBlogImage } from "@/lib/blog/images";
import { BLOG_LIMITS } from "@/lib/blog/post";
import { createClient } from "@/utils/supabase/client";

/**
 * Cover image + its alt text. The upload goes browser → Storage on a signed
 * URL minted by an admin action, then the action re-checks the stored object
 * (type and size) before the URL is accepted. The post records the URL only
 * when it is saved.
 */
export function CoverImageField({
  url,
  alt,
  onUrlChange,
  onAltChange,
  error,
}: {
  url: string | null;
  alt: string;
  onUrlChange: (url: string | null) => void;
  onAltChange: (alt: string) => void;
  error?: string;
}) {
  const input = useRef<HTMLInputElement>(null);
  const [busy, setBusy] = useState(false);
  const [uploadError, setUploadError] = useState<string | null>(null);

  async function upload(file: File) {
    const check = validateBlogImage(file.type, file.size);
    if (!check.ok) {
      setUploadError(check.error);
      return;
    }
    setUploadError(null);
    setBusy(true);
    try {
      const ticket = await requestBlogImageUpload(file.type, file.size);
      if (!ticket.ok) {
        setUploadError(ticket.error);
        return;
      }
      const { error: upErr } = await createClient()
        .storage.from(BLOG_BUCKET)
        .uploadToSignedUrl(ticket.path, ticket.token, file, {
          contentType: file.type,
          // Every upload is a fresh uuid path, so its content never changes.
          cacheControl: "31536000",
        });
      if (upErr) {
        setUploadError(`Upload failed — ${upErr.message}`);
        return;
      }
      const confirmed = await confirmBlogImageUpload(ticket.path);
      if (!confirmed.ok) {
        setUploadError(confirmed.error);
        return;
      }
      onUrlChange(ticket.url);
    } finally {
      setBusy(false);
      if (input.current) input.current.value = "";
    }
  }

  const altMissing = !!url && !alt.trim();

  return (
    <div className="grid gap-4">
      <div className="relative aspect-video w-full overflow-hidden rounded-xl border bg-muted/50">
        {url ? (
          // eslint-disable-next-line @next/next/no-img-element -- admin preview of a just-uploaded object; the public page uses next/image
          <img src={url} alt={alt || "Cover image preview"} className="h-full w-full object-cover" />
        ) : (
          <button
            type="button"
            onClick={() => input.current?.click()}
            disabled={busy}
            className="flex h-full w-full flex-col items-center justify-center gap-2 text-sm text-muted-foreground transition-colors hover:bg-muted"
          >
            {busy ? <Loader2 className="size-5 animate-spin" aria-hidden /> : <ImagePlus className="size-5" aria-hidden />}
            {busy ? "Uploading…" : "Upload a cover image"}
            <span className="text-xs">JPG, PNG or WebP, up to 5 MB. Landscape, at least 1600px wide.</span>
          </button>
        )}
        {url && (
          <button
            type="button"
            onClick={() => input.current?.click()}
            disabled={busy}
            className="absolute bottom-3 right-3 inline-flex h-9 items-center gap-2 rounded-full bg-background/95 px-4 text-sm font-medium text-foreground shadow-sm hover:bg-background"
          >
            {busy ? <Loader2 className="size-4 animate-spin" aria-hidden /> : <RefreshCw className="size-4" aria-hidden />}
            {busy ? "Uploading…" : "Replace"}
          </button>
        )}
      </div>
      <input
        ref={input}
        type="file"
        accept={BLOG_IMAGE_MIME_TYPES.join(",")}
        className="sr-only"
        tabIndex={-1}
        aria-hidden
        onChange={(e) => {
          const file = e.target.files?.[0];
          if (file) void upload(file);
        }}
      />
      {(uploadError || error) && (
        <p role="alert" className="text-xs text-destructive">
          {uploadError ?? error}
        </p>
      )}

      <label className="grid gap-2">
        <span className="flex items-baseline justify-between gap-3">
          <span className="text-sm font-medium text-foreground">Image description (alt text)</span>
          <span className="text-xs text-muted-foreground">Required to publish</span>
        </span>
        <Input
          value={alt}
          onChange={(e) => onAltChange(e.target.value)}
          maxLength={BLOG_LIMITS.coverAlt}
          placeholder="e.g. A detailer polishing the hood of a black SUV in our Houston bay"
          aria-invalid={altMissing ? true : undefined}
        />
        <span className={altMissing ? "text-xs text-amber-700" : "text-xs leading-relaxed text-muted-foreground"}>
          {altMissing
            ? "Describe what the picture shows — it is read aloud to blind visitors and used by Google Images."
